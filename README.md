# Invitation Website Template

A free invitation website template for events. Built with HTML, CSS, and JavaScript. You customize it by editing a single JSON file.

![Thumbnail](https://raw.githubusercontent.com/Rainier-PS/Invitation-Template/main/media/images/Thumbnail.avif)

## Demo

See it live: [Live Site](https://rainier-ps.github.io/Invitation-Template/)

## Features

- Edit through a JSON file, no coding needed
- Full page scroll with smooth transitions between sections
- RSVP form integration with Tally.so or other providers
- Google Maps link for venue location
- One-click Add to Google Calendar
- Clean typography and responsive layout
- Works on mobile and desktop
- Open source under MIT License

## Quick Start

1. Download the latest release ZIP from [Releases](https://github.com/Rainier-PS/Invitation-Template/releases/latest) and unzip it.
2. Fill out your event details. Use the [Usage Guide](docs/USAGE_GUIDE.md) or the online JSON Builder.
3. Create an RSVP form (Tally.so) and add the embed URL to your event.json.
4. Host on GitHub Pages, Vercel, or Netlify.

For step by step instructions, see the [Usage Guide](docs/USAGE_GUIDE.md).
